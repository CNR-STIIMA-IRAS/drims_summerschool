# drims2_summerschool
These are the main repository for the DRIMS2 Summer School:
 - [drims2_cells](https://github.com/CNR-STIIMA-IRAS/drims2_cells): Contains robot descriptions, controllers, and launch files for setting up simulations and/or establishing communication with real robots.
 - [drims2_motion_control](https://github.com/CNR-STIIMA-IRAS/drims2_motion_control): Provides APIs, ROS actions, and Behavior Tree nodes for basic robot movements.
 - [drims2_dice_simulator](https://github.com/CNR-STIIMA-IRAS/drims2_dice_simulator): Offers a simulator for a dice.

For usage instructions and setup details, please refer to each package’s README.
